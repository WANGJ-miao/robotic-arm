## task1
目前实现:
1. 输入三个关节角度输出关节力矩
2. 画出固定某两个电机旋转另一个电机时三个关节力矩的图像, 分别画出考虑摩擦力和不考虑摩擦力的情况
3. 输入最大静摩擦力, 画出自锁的三维图, 图中颜色表示摩擦力的冗余程度(我想表达的意思是目前的摩擦力距离最大静摩擦力还剩多少)
